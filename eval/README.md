# Evaluation (SciCoQA)

Harness for measuring Portolan's verification engine on SciCoQA
(`github.com/UKPLab/scicoqa`). Built in Milestone 10. The loader will read the dataset format from
the official repository, and the scorer will implement the benchmark's own recall/precision and
matching definitions, documented here once implemented.

No numbers are reported here until they come from an actual run.
